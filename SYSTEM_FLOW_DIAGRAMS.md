## 4. Database Interaction Flow

```
???????????????????????????????????????????????????????????????
?                 DATABASE OPERATIONS             ?
???????????????????????????????????????????????????????????????

???????????????????
?     USERS       ?
???????????????????
? user_id (PK)    ?????
? user_email      ?   ?
? user_password   ?   ?  ONE-TO-ONE relationship
? role_id         ?   ?  (user_id is UNIQUE in fingerprint_templates)
? is_active       ?   ?
???????????????????   ?
        ?
          ?????????????????????????????????
          ?       ?
       ? FINGERPRINT_TEMPLATES          ?
          ??????????????????????????????????
          ? ftemp_id (PK)                  ?
          ? user_id (UNIQUE, FK) ???????????
  ? ftemp_data (BYTEA)          ?  ???? Binary fingerprint template
          ? ftemp_name (VARCHAR)           ?
          ? ftemp_created_at (TIMESTAMP)   ?
   ??????????????????????????????????

QUERIES USED:

1. Login Authentication:
   SELECT ftemp_id, user_id, ftemp_data, ftemp_name, ftemp_created_at
   FROM fingerprint_templates
   ORDER BY ftemp_created_at DESC;
   
   (Get ALL templates, then loop through to find match)

2. Check Registration Status:
   SELECT ftemp_id, user_id, ftemp_data, ftemp_name, ftemp_created_at
   FROM fingerprint_templates
   WHERE user_id = @user_id;

3. Create New Fingerprint:
   INSERT INTO fingerprint_templates (user_id, ftemp_data, ftemp_name, ftemp_created_at)
   VALUES (@user_id, @ftemp_data, @ftemp_name, @ftemp_created_at)
   RETURNING ftemp_id;

4. Update Existing Fingerprint:
   UPDATE fingerprint_templates
   SET ftemp_data = @ftemp_data,
       ftemp_name = @ftemp_name
   WHERE user_id = @user_id;

5. Delete Fingerprint:
   DELETE FROM fingerprint_templates
   WHERE user_id = @user_id;
```

- ? Visual & audio feedback
- ? Role-based access control
- ? Session management
