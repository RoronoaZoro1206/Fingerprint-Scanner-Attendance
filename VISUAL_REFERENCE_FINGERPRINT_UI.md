## ? Accessibility Features

### **Color Contrast Ratios**
```
? Success Text on Light Background: 7.3:1
? Error Text on Light Background:   8.1:1
? Info Text on Light Background:    7.8:1
? Button Text on Dark Background:   21:1

All ratios meet WCAG AAA standards (? 7:1)
```

### **Focus States**
```
All interactive elements have visible focus states:
- Buttons: Blue outline (2px solid #3b82f6)
- Inputs:  Blue outline (2px solid #3b82f6)
- Scanner: Blue border increase (3px ? 5px)
```

### **Screen Reader Support**
```
- All icons have aria-labels
- Status changes announced
- Modals have proper aria attributes
- Form fields have labels
- Error messages associated with inputs
```
