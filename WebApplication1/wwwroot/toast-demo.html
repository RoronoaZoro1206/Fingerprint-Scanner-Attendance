🎉 Toast Notification System

Modern, clean, and reusable toast notifications for your application

Basic Toast Types

Toast.success("Operation completed successfully!");
Toast.error("Something went wrong!");
Toast.warning("Please review your input.");
Toast.info("New updates available.");

CRUD Operations

Toast.created("Department"); // "Department created successfully!"
Toast.updated("Student"); // "Student updated successfully!"
Toast.deleted("Record"); // "Record deleted successfully!"
Toast.createError("Department"); // "Failed to create department."

Toast Positions

Toast.topLeft("Message", "success");
Toast.topRight("Message", "info");
Toast.center("Message", "info");

Custom Duration

showToast("Quick message", "info", { duration: 1000 });
showToast("Persistent", "info", { duration: -1 });

Custom Styling

showToast("Custom color", "success", { backgroundColor: "#6366f1" });
showToast("Large text", "info", { style: { fontSize: "18px" } });
showToast("No icon", "success", { showIcon: false });
